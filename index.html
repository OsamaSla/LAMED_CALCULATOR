קוטר יחיד (D)

מצב 0 — חישוב L, α (נתונים: H, D, F, r)

L = √(H² − 2DF + F² − 4Fr) // אורך חיתוך T = (r + D/2) · tan(α/2) // היסט קשת α = −atan( N / Dnm ) // זווית חיתוך (מברדיאנים לדרגות) N = DH + 2Hr + (−D + F − 2r) · L Dnm = −D² + DF − 4Dr + 2Fr − 4r² − HL

מצב 1 — חישוב L, H (נתונים: α, D, F, r)

T = (r + D/2) · tan(α/2) L = F / sin(α) − 2T H = 2T + F / tan(α)

מצב 2 — חישוב H, α (נתונים: L, D, F, r)

H = √(L² + 2DF − F² + 4Fr) α = −atan( N / Dnm ) // כמו במצב 0

שני קטרים (D1 + D2)

F1 = D2 + F − D1 (בריחה שמאל)

מצב 3 — חישוב L1, L2, α1, α2 (נתונים: H, D1, D2, F, r)

L1 = √(H² − F1 · (4r + 2D2 − F1)) L2 = √(H² − F · (4r + 2D1 − F)) α1 = atan( (H·F1 − r²) / (F1 · (F1 − r)) ) α2 = atan( (F·H − r²) / (H² + H·r + r²) )

מצב 4 — חישוב L1, L2, H (נתונים: α, D1, D2, F, r)

T1 = (r + D1/2) · tan(α/2) T2 = (r + D2/2) · tan(α/2) L1 = F1 / sin(α) − T1 − T2 L2 = F / sin(α) − T1 − T2 H = T1 + T2 + F / tan(α)

מצב 5 — חישוב H, α1, α2 (נתונים: L, D1, D2, F, r)

H = √(L² + F · (4r + 2D1 − F)) α1 = atan( (H·F1 − r²) / (F1 · (F1 − r)) ) α2 = atan( (F·H − r²) / (H² + H·r + r²) )
